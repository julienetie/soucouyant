# Security

## Supported versions

Soucouyant is in alpha. Only the latest release gets fixes.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through [GitHub's vulnerability reporting](https://github.com/julienetie/soucouyant/security/advisories/new) instead.

Include what an attacker could do, the affected version, and the smallest code that shows it. You'll get a reply within a week.
