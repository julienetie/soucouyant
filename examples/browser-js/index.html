Soucouyant examples

Four single-page apps, each one HTML file with its JavaScript and CSS inline and commented. Every page has an Under the hood panel showing the state, the subscriptions and what Soucouyant is doing.

  1. Pepperpot Pantry

    A shop that uses the core alone, as fully as a shop allows: a catalogue loaded while pending, a basket locked by the mutex during payment, a checkout built on finite states, and discount codes checked by async callbacks.

    soucouyant-core.js

  2. Atelier

    A paint editor with a Photoshop-style history panel. Every stroke is a frame on the chain; undo, redo, the scrubber and bookmarks move the head, and the history survives a reload.

    soucouyant-temporal.js, indexeddb.js

  3. Turnstile

    A walk cycle driven by a keyframe trajectory, in a world where time can run backwards. Inverted functions undo what the proceeding functions did: footprints lift, a broken vase mends.

    soucouyant-temporal.js

  4. Scenario desk

    Live exchange rates with what-if scenarios. Each scenario is a timeline branched off the market, running alongside it with its own history.

    soucouyant-polychrony.js
Run npm run examples from the repository root to build Soucouyant and serve these pages.
